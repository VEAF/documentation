    Conventions¶

    • PNG, width ≥ 1280 px when possible.
    • File names are lower-case, hyphen-separated, and match the placeholder paths already referenced in the Markdown (e.g. pilot/f10-veaf-submenu.png).
    • Until a screenshot is captured, its placeholder reference renders as a broken image — this is expected during the documentation overhaul.
